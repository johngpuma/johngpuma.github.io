Catan 1v1 Post-Game Analyzer Side project

A Chrome extension records 1v1 games by decoding Colonist.io's real-time WebSocket / MessagePack protocol, and a translator maps its 54-vertex, 72-edge board onto the Catanatron rules engine. The analyzer then replays the match and scores every decision by win probability using seeded Monte-Carlo rollouts, flagging statistically significant blunders and showing the move the engine would have made instead. Post-game only, with no live assistance.

JavaScript Python MessagePack Chrome Extension (MV3) Catanatron Monte-Carlo rollouts

Research paper for COMM 324 with Prof. Jeff Hancock on how human code reviewers treat AI coding agents. Analyzed 7.7M agent-authored pull requests across 2,800+ GitHub repositories in Python.
